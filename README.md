## Descripción del Proyecto
Este proyecto consiste en una herramienta integral de consultoría y visualización de datos para una empresa comercializadora en El Salvador. Utiliza **Pandas** para la inspección y análisis estadístico de inventarios en 5 sucursales (San Salvador, Santa Ana, San Miguel, La Libertad y Sonsonate) y **PyQt5** con **Matplotlib** para la generación de una interfaz gráfica interactiva.

## Estructura del Repositorio
- `main.py`: Código fuente con el análisis de Pandas y la interfaz GUI en PyQt5.
- `inventario.csv`: Conjunto de datos del inventario de las sucursales.
- `requirements.txt`: Dependencias del proyecto.
- `.gitignore`: Archivos excluidos del control de versiones.
- `Informe_Consultoria.pdf`: Informe detallado en PDF enviado a la gerencia.
